# 보안은 만들기 보다 뚫기가 쉽다

**Category:** 일기장
**Original URL:** https://blog.naver.com/xpfkwh56/224356589649

​

1. 성세천하 플레이 하려면,

중국 결제 계정 필요함

​

2. 근데 그거 없어도 할 수 있음

​

3. 먼저 원본 파일을 다운 받고,

엔진 분해해서 보안장치 다 깨고

​

결제 우회하는 스크립트 찾아서

그 부분만 바꾸면 유료 재화를

내 마음대로 조정해서 쓸 수 있음

​

**4. 같은 방식으로, 서버에 전달되는**

**데이터 자체는 조정할 수 없지만**

​

오프라인 1인 플레이 기준이라면

치트 크랙본 만들어서 플레이 가능

​

**5. 이걸 할 수 있으면 좋은 이유**

​

부모님 몰래 현질 안 해도 됨

​

6. 그리고 이 논리는 서버에서 보내는

API 가로채기 하는 방법과 **거의** 유사함

​

1) 인스타/스레드 크롤링 할 때,

크롬 말고 파폭/오페라 브라우저 쓰면

일단 지금 기준으로 우회할 수 있음

​

2) 네이버 애드포스트 API 우회하면

구글 애널리틱스랑 **'거의'** 비슷하게

수익 창출 경로 추측하는 것이 가능함

​

3) 국내/외 웹 서비스들은 **'의외로'**

보안 취약점들이 **'매우매우'** 큰데,

​

인공지능 다룰 수 있고, 콤퓨타 좀 알면

​

웹소설 공짜로 보기, 만화 공짜로 보기,

같은 것을 조심스럽게 시도해볼 수 있음

​

**\* 회사가 보안에 투자를 많이 하면,**

**해결할 수 있는데 굳이 ,, 싶어할 듯함**

**​**

아마? 길어야 1-2년 안에 법제화로 막을 듯

​

비권한 정보에 **'접근'** 하려는 시도 자체를

불법으로 만들어서 막지 않을까 싶음
