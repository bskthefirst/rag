# 인공지능 티 안 나게, LLM 쓰는 법
**Date:** 21시간 전
**Category:** 일기장
**Original URL:** https://blog.naver.com/xpfkwh56/224379940158
---

1. 깃에 온갖 잡기술 많이 있는데,

몇 개 봤지만 그런다고 되지도 않음

​

바이브 코딩이 쉬워지면서,

적당히 갖고 놀다가 고양되면

​

깃에 올려서 스타 받는 재미로

뿌리는 분들 있는데 잘 거르시고

​

모르겠으면 아이디어만 따거나

참고만 하듯이 보는 것을 권합니다

​

돌고 돌아 결국 **'설계'** 를 잘 해야 됩니다

​

2. 먼저 AI 티를 지우려면

**돈** 이 많이 듭니다

​

근본적인 방법은 **학습** 이고,

가장 쉬운 방법은 이겁니다

​

**\* 편의상 원리는 생략합니다**

​

텍스트가 들어갈 부분의

설계 흔적만 남긴 다음에,

​

그 부분에 들어갈 글자를

조판해서 씌워 넣으세요

​

예를 들어,

​

제목 = [노출 키워드가 포함된 제목]

소제목1 = [서론]

소제목2 = [본론]

소제목3 = [결론]

​

이렇게 먼저 글을 **'구조화'** 하고,

​

LLM 한테 대괄호 안에 들어간 부분만

edit 처리해서 **치환** 하라고 지시하세요

​

통집필 할 때보다 품질이 훨씬 좋아집니다

​

3. 이걸 미시적이게 짜면 짤수록,

글이 점점 **'교묘'** 하게 잘 나옵니다

​

1) 오늘 나는 학교에 갔다

2) 학교에 가서 밥을 먹었다

3) 밥을 먹었는데, 반찬으로

소세지가 나왔다

​

라는 글을 쓴다고 가정하면,

​

[어디에 갔는지 적어라]

[가서 뭐 했는지 적어라]

[뭐 했고, 어떤 일 있었나 적어라]

​

이렇게, **'얼개'** 만 남기고

그 안을 LLM 이 채우게 하는 것임

​

4. **'자동화'** 레벨로 들어가면,

LLM 특유의 비결정성을 응용해

​

각 치환값이 어떻게 연산해서

들어갈 것인지 트리화 할 수 있음

​

예를 들어, 특정 대괄호 안에 들어갈

케이스를 [시간, 장소] 라고 가정하고,

​

시간에 묶이는 벡터 임베딩,

장소에 묶이는 벡터 임베딩 값이

어떻게 서로 얽히는지 연산 시킨 후

​

특정 키워드에서 수렴 되는 값을

선호하도록 결정한다고 치면,

​

시간적인 단서가 많을수록

시간에 수렴된 문장이 나오고,

​

장소적인 단서가 많을수록

장소에 수렴된 문장이 나옵니다

​

글 전체에서, 각 문단의 구조 설계,

문단 전체에서 각 문장의 구조 설계,

문장 내에서 어휘 배치 설계 같은 걸

​

촘촘하게 케이스를 잘 분리해낼 수록

이게 사람인지, 기계인지 구분이 안 감

​

5. 단, 네이버는 제가 아는 선에서

이걸 **'구분하지 못한다고'** 보기 때문에

​

하면 좋지, 못 한다고 지장이 있진 않음

​

최소한의 **성의** 정도만 있어도,

AI 어뷰징 거의 안 걸립니다
