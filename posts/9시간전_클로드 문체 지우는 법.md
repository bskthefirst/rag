1. 사다리, 관문 같은 **다빈출** 어휘 있음

​

발생하는 이유는 LLM 은 기본적으로

의미가 얽히는 벡터값 방향으로 수렴하는데

​

글쓰기 데이터로 쓰는 것의 대부분은,

​

영어권 **'제도권'** 데이터 이기 때문에

거기서 쓰는 관습적 어휘들이 묶임

​

모델은 달라고, 데이터는 대체로 공유하니

각을 잡고 오래 사용하고 싶으신 생각 있으면

​

미리 어휘 카탈로그를 만들어 둔 다음에,

그게 나타날 때 마다 전환해 쓰면 됩니다

​

즉, 장기 에이전트 작업 설정 해놓고

3천자, 5천자씩 계속 뿜게 한 다음에

​

코퍼스 체크해서, 삭제/대체 하면 됨

​

대시, · (중간점), 갑자기

개뜬금없는 명사구 마무리

​

1.2.3 1)2)3) 안 쓰고

첫째, 둘째, 셋째

​

같은 것도 그렇읍니다

​

**2. LLM 이 글을 읽는 방향은 둘 임니다**

​

하나는 **'토큰'** 바탕으로 표면을 읽고,

하나는 **'의미'** 를 묶어서 문맥을 읽음

​

전자를 결정론 적이라고 하고,

후자를 비결정론 적이라고 하는데

​

결정론 = 100억번 해도 결과 똑같

비결정론 = 2번만 해도 결과 다름 임

​

전자라고 좋고, 후자라고

무작정 좋고 가 아니고

​

각자 쓰임이 공존합니다

​

특정 어휘를 말끔히 교체 하겠다

같은 것은 스크립트가 더 좋습니다

​

**\* 결정론적**

​

greb 으로 긁고 edit 하면 됩니다

​

근데 이렇게 하면 **전파성** 이라거나,

​

기계적 교체에서 부자연스럽게 문맥이

작동하는 구간이 100% 발생합니다

​

그래서, pass 구조를 짜야 됩니다

​

기본적으로 문장 전체에서

사전식 카탈로그에 있는 것을 찾고,

​

찾아낸 리스트로 엔티티 기반의

교체를 시도했을 때,

방향값 변화를 봅니다

​

그래서 문제가 없으면 pass

문제가 없으면 LLM 한테 갑니다

​

LLM 은 기준치 이하의

의심 구간이나 위반 항목이 생겼을 때

​

그걸 어휘, 구, 절, 문장, 문단, 글 전체

레벨에서 판단하고 교체 여하를 봅니다

​

단, 주의할 점은 네이티브 한국인이

쓸 법한, 납득 가능한 수준의 코퍼스가

미연에 입력된 상태가 아니라면

​

아주 높은 확률로 **밋밋하게** 수렴합니다

​

**\* 로컬 쓰라고 목 놓아 외치는 이유**

**​**

프론티어 레벨이라도, 그냥 프롬프트로

​

**'어색한 글자 바꿔줘, ai 티 안 나게 해 줘'**

라고 한들, 절대 결과 마음에 들 리 없으니

​

**\* 통상적으로 인간적임, 이라는 어휘는**

**모델에 관계없이 인문, 윤리와 묶입니다**

**고전철학, 포스트모던 이런 계열이란 뜻**

​

1차로 기계전환 하시고, 2차로

바꿨을 때, 해당 문장의

전파성 여부만 봐달라고 해도

​

**'어지간'** 하면 구분하기 어려워질 것 임
