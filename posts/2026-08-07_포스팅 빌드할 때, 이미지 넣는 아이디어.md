# 포스팅 빌드할 때, 이미지 넣는 아이디어
**Date:** 2026. 8. 7. 16:05
**Category:** 일기장
**Original URL:** https://blog.naver.com/xpfkwh56/224371203178
---

1. LLM 이 먼저 글 전체를 읽고,

이미지가 들어갈 부분을 기획한다

​

기획이 끝나면, IMG(\d+) 형태로

이미지가 들어갈 위치에 마커를 쓴다

​

2. 생성형 이미지 모델을 사용해,

기획된 이미지를 실제로 생성한다

​

글의 n번째 마커 = 파일 img\_n.png

규칙으로 숫자쌍을 맞춰서 이미지 배치

​

**\* IMG2 라고 적힌 영역을 클릭 → Home, Shift+End, Delete로 그 줄 글자만 지움 → 커서가 빈 줄에 있는 상태에서 에디터의 사진 버튼 클릭 → 파일 선택창이 뜨면 img\_2.png 경로를 넣어줌 → 업로드 6초 대기 → 방금 들어간 이미지를 선택해서 상세 설정**

​

3. 이미지 배치가 끝나면, 비전 모델이

생성된 이미지의 정합성을 파악한다

​

1) 프롬프트에 맞게 생성 되었는가?

2) 오류없이 제대로 그려진 상태인가?

​

둘 다 문제 없으면 그대로 다음 스텝 가구,

문제 있으면 그 부분만 다시 그려서 올림

​

4. 사람이 행동하는 것을

고대로 스크립트로 구현하심 됨
