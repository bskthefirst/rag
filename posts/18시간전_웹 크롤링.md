지금 로칼 돌리거나, 미약하게나마

보안 레벨로 가로채기 하는 사람이

적기 때문에, 이게 아직 돌아가는 건데

​

점점 코딩 전체 역량이 올라가게 되면,

​

나중에는 유료 API 오피셜하게 받아서

사용하는 사람 아닌 이상 못 쓰게 될 것임

​

**왜 why?**

​

이게 **실제로** 공짜인 것이 아니고,

​

나 대신 비용을 지불하는 사람들이

막는 비용보다 놔두는 비용이 아직은

저렴하니까 놔두고 있는 것이기 때문

​

텔레나, 디코방 같은 곳 들어가보면

​

클로드/지피티 같은 것을

무료로 쓸 수 있는 통로 준다는데

​

실상은 dom + 매크로 단순 작업해서

무한 IP/계정 만들고 돌리는 검니다

​

**\* 극히 드물게 진짜 API 피싱하는**

**경우도 없진 않겠지만 적어도**

**제가 봤던 경험상, 다 금방 막힘**

**​**

지금도 여전히 최블이니, 뭐니 하면서

돈 많이 버는 분들이 없지는 않지만

​

결론적으로는 비슷한 상황 될 것으로 봄
