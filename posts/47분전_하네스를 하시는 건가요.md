# 하네스를 하시는 건가요?
**Date:** 47분 전
**Category:** 일기장
**Original URL:** https://blog.naver.com/xpfkwh56/224331218870
---

**1. 인공지능이 배우기 어려운 이유**

​

그리고, **'감'** 도 안 잡히는 이유

나쁘게 말하면 **근본** 이 없기 때문

​

2. 하네슨지, 하기슨지가 뭔데요?

​

모델 = 자동차 엔진

하네스 = 차체

​

엔진은 거의 전부지만 전부는 아님

차체가 있어야 엔진을 돌릴 수 있음

​

핸들, 계기판 이런 것 없으면

특히 **'운전'** 자체를 할 수 없는데,

​

하네스 가 운전을 하게 만드는 틀 임

​

**3. 하네스가 있으면 무엇이 가능함?**

​

아주 쉽게 말하면 **'활용'** 이 됨

​

자연 동력원이 있으면 뭘 할 수 있나요?

전기도 만들 수 있고, 어쩌고 저쩌고,

​

전기가 있으면 뭘 할 수 있나요?

어쩌고 저쩌고 처럼 하는 것이 된단 것임

​

**\* 이건 규정조차 어렵고, 규정을 해도**

**그게 상황 마다 달라서 애매할 때가 많음**

**​**

4. 하네스 같은 것 할려면 얼마나 듭니까?

​

하네스는 정해진 자격증/표준 스펙이 아니라,

​

모델 바깥에서 루프를 굴리는 레이어를 만들면

사후에 그걸 지칭하는 기능적 롤에 불과하므로

​

**'배우는 것'** 자체가 **'불가능'** 함

​

물론 재귀성이 있고, 반복되는 기능들이

아예 완전히 없냐 하먼 그건 아니긴 하지만,

​

알아도 그냥 어휘 수집 레벨 밖에는 안 됨

​

5. 예를 들어보겠음,

​

1) 싱글샷이냐? 에이전트 루프냐?

​

2) 리액트냐? 리플렉션 구조냐?

멀티 에이전트 오케스트레이션이냐?

​

3) 컨텍스트 관리에 있어서, 전체 이력을

직접 관리하냐? Rag로 하냐?

스크래치 패드로 하냐? 압축해서 하냐?

압축은 어떤 방식으로 하냐? 등등

​

4) 도구 호출은 펑션 콜링을 하냐?

툴 콜링을 하냐? 텍스트 파싱을 하냐?

스크립트 코드 실행을 하냐? 반자동 하냐?

​

5) 검증 루프는 휴먼 게이트냐?

기성 게이트 키퍼냐?

서브 에이전트는 쓰냐 안 쓰냐?

​

라그 하네스, 코딩 에이전트 하네스,

워크플로우 하네스, 테스크 하네스, 등등

​

이름만 하네스지, 얘네는 걍 **다른 애들** 임

​

**6. 그래서 방향을 바꿔야 됨**

​

고수들이 하네스를 써서, 막 반자동 어떻게 해서

컴퓨터 켜놓기만 하면 엑소시스트 귀신 들린 마냥,

​

뚝딱 세컨브레인 만들어서 화려하게 잘 돌리더라

나도 저거 배워서 해야지 또는, 누가 어디 용하다는

신기한 하네스 배워서 쓰니까 효과가 좋다더라

​

라는 식으로 들어가면 **'거의'** 답이 없을 확률 큼

​

**7. 새콤달콤 이라는 디쟈트가 있음**

​

이걸 그냥 먹어도 됨

​

**근데 얼려 먹으면 더 맛있구,**

**녹여서 물에 타먹을 수도 있음**

​

얼리는 법을 알면?

녹이는 발상도 공짜임

​

새콤달콤 만 되는 것이 아니고,

마이쮸 를 써도 그게 적용될 수 있음

​

그리고, **'실타래'** 라는 것이 있는데

잘 가공하면 이런 것도 만들 수 있음

​

이게 사람들이 입에 달고 사는,

​

**'AI'** 가 할 수 없는 일이고

**'인간'** 이 앞으로 **'해야 될'** 일임
