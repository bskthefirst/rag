# 로컬 워크스테이션을 미리 산 사람들의 잇점
**Date:** 1시간 전
**Category:** 스냅
**Original URL:** https://blog.naver.com/xpfkwh56/224430733518
---

1. **'미리 해봤다'**

​

지금 프론티어에 나오는 온~갖 서비스들은

​

로컬 오픈소스에서 심하면 2년, 증말 짧아봤자

3개월 전후 무렵에 이미 다 물고 뜯고 했던 것 임

​

물론 내가 전부 아는 것은 아니지만,

​

프론티어 레벨에서 진짜 난생

처음 보는 기술로 나온 건,

​

**덕테이프 렌더링 밖에 없음**

​

남들이 프롬프트 엔지니어링 어쩌고 하면서,

글자 입력해서 출력 나오길 기대하고 있을 때

​

가중치 만지고, 모델 돌려보면서

실제 출력 작업 안정성 확인하고,

​

오케스트레이션 하네스 ,,

​

**\* 하네스란 말도 난 사기 같음**

​

라던가, 자급자족 서비스 만들어서

혼자 돌려보는 그런**'경험'** 들이

​

나중에 AI 를 어디에 어떻게 갖다 붙여도

원리가 비슷하니까 써먹기에 좋았던 것 임

​

일례로, 제가 왜 LLM 운용을 쉽게 하냐면

​

저는 RAG 구축도 해봤고,

​

컴피 파이프라인 무인화 가동 하면서

텍스트 인코더 내부 모델을 실제 뜯어봄

​

로컬 모델이 toolcall 안 될 시절에,

​

빈칸만 빵빵 뚫어놓고 일일히

확률값 빈도값 계산하면서,

​

깎던 과정이 있었으니 처음부터

목적 생기면 지금 이 상황에서는

​

어디에, 뭐를, 어떻게 써야 된다

같은 것을 **'해봐서'** 아는 것

​

엔트로픽에서 콘솔 간 채팅 서비스 나왔을 때,

바로 전날 자체 서비스로 구축해서 돌리고 있었고

​

구현, 최적화, 기술스텍 나오면 gpu 빌려다가

쓸 수 있는 것은 내 상황에 실제로 다 돌려봤었음

​

벤치만 해도, 컴퓨터 2대 들고

이틀 정도 틀어놓으면 내 목적 기준,

​

어떻게 정렬 해야 하는지 잡을 수 있으니

무슨 모델 받아야 해요? 같은 고민이 없음

**​**

**2. 안정적이게 굴릴 수 있다**

​

프론티어 모델이 **'당연히'** 성능 더 좋음,

​

근데 아주아주 좁은 영역에서

특수 작업을 전문화 시키게 된다면,

​

시시각각 업데이트 되는 프론티어 모델의

성능 향상이 **'노이즈'** 로 여겨질 수 있음

​

신모델 나온다?

​

그럼 심하면 원래 굴리고 있던 시스템을

처음부터 다시 **싹 다** 고쳐서 해야 될 수 있음

​

10% 정도 성능 향상이 된다고 가정하고,

내가 그 10% 성능 향상을 위해서

​

여태 신뢰할 수 있게 짜놨던 모든 라인을

전부 뒤져봐야 된다면 그건 좀 어려운 일 임

​

근데 특별히 문제 없이 잘 돌아가고 있으면,

아주 부분적으로만 개선을 해보거나

​

저처럼 컴퓨터 2대 놔두고,

​

1대 에는 안정적으로 운용 유지하고,

​

1대 에서는 테스트하면서 점진적으로

내가 이식할 모델 환경을 구축할 수 있음

​

3. 이게 실상, 로컬 더 빨리 만진

사람이 얻을 수 있는 장점의 전부임

​

**그럼 왜 지금은 굳이 사지 말라고 할까?**

​

걍 말이 안 되게 비싸요

​

저 컴퓨터 살 때, 실제 제가

지불한 건 그거보다 쪼끔 더 적고,

​

계산이 복잡하지만 암튼 잡아본다면

대당 천만원 주고 컴퓨터 샀는데

​

**\* 9950xd, 128gb, 5090**

**​**

오늘 글카만 뜯어서 팔아도 천만원 임

​

제가 인공지능 만져서 번 수익 보다,

인건비 빼면 그냥 혹시나 하는 생각에

몇 대 더 샀다가 되판 수익이 훨씬 큼

​

**\* 여태 갖고 있었으면 더 벌었을 거고 ;;**

**​**

기점이 28년 무렵인데,

엔비디아가 돈 잘 버니까

​

서로 너나 할 것 없이 경쟁 제품 나왔고,

토큰값 도 하루가 멀다하고 떨어지고 있음

​

제 시절에는 api 를 유료로 돌리는 것보다

gpu 대여 해서 돌리는 것이 이익 이었는데,

​

기계만 산다고 뭐가 되는 것이 아니기 때문에,

​

**'일단'** 빌려 쓰면서 내가 할 작업들을 조금

불편해도 많이 많이 시도해보는 것이 더 좋음

​

저는 약 6개월 정도 1660 노트북 들고,

gpu 빌려서 해보고 싶은 것들 다 해봤었고

​

컴퓨터 바꾸자마자 **못 해봤던 걸** 다 해봤음

​

4. 로컬을 **'그냥'** 해보고 싶어서 하는 거라면

취향이니까 그건 뭐 누가 할 얘기가 아니지만,

​

위에서 말한 로컬의 몇 가지 장점들,

무검열/프라이버시/막대한 실험 성능

​

같은 것들을 살릴 수 없으면 **굳이, 굳이** 임요

​

1) 그냥 영상 만들어서 쌀먹 하고 싶은데요?

​

힉스필드, 클링 이런 거 쓰세요

배우다가 시간 다 가요

​

영상 만들려면 뭘 잡아도

지금은 300-400 시작인데,

​

그거 주고 사도 답답할 확률 **큽니다**

​

2) LLM 로 이거도,

저거도 해보고 싶은데요?

​

내가 **메가 데이터** 를 보유하고 있다

기가 단위 정보를 어떻게 써먹어야 된다

​

이런거 아니라면 최소한 2-3개월 이라도

프론티어 모델 구독해서 사용 먼저 해보고,

​

내가 그래도 혼자 열심히 인프라 구축하면

소넷 이상, LUNA 이상 만들 수 있겠는데?

​

라는 **'각'** 이 나올 때, 구매하세요

​

비개발자 기준, 밥 먹고 저거만 쳐다보고 있어도

로컬 돌리는 지식 수준 얻으려면 **최소 3개월** 임
