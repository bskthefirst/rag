**1. 딥리서치 모델 완성**

​

**'나'** 처럼 구글링 해서 필요한 자료 생기면,

개인화 된 환경 제외하고 들어가서 다 조사함

​

영어권, 중어권, 일어권, 한국어권 다 가능

​

**\* 영 > 한 > 중≒일 성능**

​

지시에 따라 다른데, 짧으면 15분

통상 1-2시간 정도 걸리고 최대 4시간

​

**성능은?**

​

**'신용점수 올리는 법'** 찾아 달라고 하면,

​

1) 신용등급 → 신용점수로 바뀜

2) 신용점수 인플레이션 발생해서 변별력 X

3) CSS 점수가 중요한데 비공개 정보임

​

4) 대신 4대 은행 우수고객 기준이 있는데,

그걸로 Proxy 하면 각 은행사에서

요구하는 요구 기준으로 **대리지표 가능**

​

5) 4대 은행 우수고객 기준은 이거임

​

까지 나옴

​

교육 정보, 입시 정보, 공고 같은 것은

1차 데이터 다 뒤져서 찾아주는 정도고,

​

유튜브에서 정성 데이터도 라우팅 잡음

​

맘카페 가입 안 해도, 나 혼자서

정보 부담 없이 어지간한 건 접근 가능

​

**2. 인텔리전트 자율 브라우저**

​

**딥리서치 만들면서**

**제일 오래 걸렸던 작업**

​

내 목표는 사람처럼 인터넷을

제약 없이 할 수 있는 AI 였고,

​

프론티어 모델에 있는 가드레일,

세이프가드, 정책 에 대한 제약 X

​

**\* 아무 선행정보 주지 않아도 본인이 직접**

**url 찾아내서 ㅂㅌㄲ나 eesva 같은 사이트**

**텔레그램 채널 찾아내서 접속해낼 수 있음**

**​**

**시각 정보 바탕으로 진짜 사람 처럼 우회함**

**​**

로컬 자원이라 토큰 X

라는 것이 가장 큰 장점

​

당연히 대기업에서 노가드로 하면

내가 만든 것보다 성능 훨 좋겠지만,

​

피차 그건 못 해주기 때문에

내가 만든 것이 더 나음

​

1) 검색/방문 기록 확인해서 북마크

​

2) 예전에 방문했던 페이지에서

유의미한 정보가 있으면 캐시에 넣고

다시 열어보지 않아서 자원 효율화

​

진짜 **'지시'** 만 하면, 즉석에서 코딩해서

수행하고 한글로 번역까지 해줄 수 있음

​

재귀 학습도 있어서, 수행하면 수행할수록

자기가 예전에 했던 결점을 보완하기도 함

​
