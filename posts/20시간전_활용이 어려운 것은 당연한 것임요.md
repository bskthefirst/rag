​

**\* 근데 이게 되면 다들 취직을 안 함**

**​**

LLM 에서 아키텍처를 다루면

못 받아도 최소 8천 시작 임

​

**\* 국내 기준, 2억이 캡이고 마찬가지로**

**이게 되는 사람이면 보통 취직을 안 함**

**​**

전자는 시각 정보와 관련된 데이터 주면

그거를 결과적인 산출물로 만드는 일을,

​

후자는 쿼리 기반으로 하는 엔지니어링,

사소하게는 PM/PL 할 수 있으면 취직 됨

​

**남조선 좋소에서 기술만 있으면**

**연봉 1-2억을 주면서 사람을 쓴다?**

**​**

이거부터가 지금 먼가 단단히 **이상하다**

라는 직감을 느낄 수 있어야 맞다고 생각

​

똑같은 시간, 똑같이 콤퓨타를 만져도

VLM 을 하면 LLM 보다 비싸고

​

똑같이 LLM 을 해도

루프를 돌리면 더 비쌈

​

기왕 같은 성적이고

당장에 잘 모르겠으면

​

대개 의대를 가는 이유가 있듯이

잘 모르겠으면 비싼 기술이 답 임

​

**\* 공급이 적고, 수요가 많거나**

**부가가치 폭 자체가 큰 경우 많음**

**​**

많이 만져보라는 이유는

이 직종의 직업, 직무를 지금

​

**'뭐라고 불러야 되는 줄'** 도

약속이 안 된 상태라 그럼

​

천상계는 아예 언터처블이고,

모르는 사람들은 아예 모르니까

​

중간에서 조금만 해도 효율 좋음

​

1) 아예 그냥 손도 못 쓴다

2) 모델 몇 개 구독 해봤다

3) 익숙하게 쓰고 있다

4) 로컬로 여러 가지 써봤다

5) 깎아봤다

6) 파이프라인 돌려봤다

​
