1. **camoufox** 검색

​

스텔스 헤드리스

브라우저 입니다

​

그걸 어디에 쓰나요?

​

봇탐지 **'연구'** 를 할 때 씁니다

​

1) **camoufox** 를 쓰면 봇탐지 안 걸린다 (x)

​

빌게이츠 할애비가 와도 걸립니다

다만, **'확률'** 을 내려줄 순 있습니다

​

그럼에도 불구하고,

저거 알았다고 바로 쓰면 안 됨

​

이런 것이 있구나, **'만약'**

내가 안다면 남도 알 것이다

​

빨리 졸업하고 다음 스텝 가자,

라고 마음을 먹어야 좋읍니다

​

2) 남이 **camoufox** 를 쓴다고

**가정하고** 내가 잡아보자

​

하고, 절대 **'오래'** 묶이지 말고

최대한 아이디어를 발산 시킵니다

​

3) 그럼 네트워크 가로채기, 크롤링,

이런 것들에 자연스럽게 닿게 되고

​

세련된 포스팅 활동을

할 수 있어 짐니다

​

**2. CDP 크롬 결속할 때, 팁**

​

먼저 디버그 크롬 포트를 엽니다,

여기 까지는 그래도 **찾으면** 나오는데요

​

**\* 각기 다른 --user-data-dir**

​

1) 각 브라우저 페이지 내부에서 DataTransfer 생성

2) ClipboardEvent('paste')를 해당 에디터에 직접 전달

​

**3) 여기가 중요합니다**

​

const dt = new DataTransfer();

dt.setData('text/html', h);

​

const e = new ClipboardEvent('paste', {

clipboardData: dt,

bubbles: true,

cancelable: true

});

​

el.dispatchEvent(e);

​

이걸 하면 **병렬 격리**가 됩니다

​

이미지도 OS 파일 선택창을 건드리지 않고

DOM.setFileInputFiles로 넣을 수 있음

​

3. Rust 로 **API 없이** 연결된 모바일 장치로

**메시지** 를 보내는 프로젝트를 시도해 보세요

​

옛날 같았으면 아예 불가능할 수 있는 얘긴데,

지금은 AI 가 좋아져서 일단 길은 열립니다

​

4. 어뷰징 스팸 필터는

**'공통'** 으로 잡힙니다

​

원래 **'추정'** 이었는데, **'확증'** 함

​

단일 신호가 아니고 복합 신호가

지속적으로 나타나면 샷다 걸림

​

이건 우회할 수 있는 방법이 없으니,

괜히 대기업이랑 싸울 생각 하지 말고

​

내 노이즈 패턴을 중간 중간

섞어주는 것이 제일 쉽읍니다
