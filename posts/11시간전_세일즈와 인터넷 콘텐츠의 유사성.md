# 세일즈와 인터넷 콘텐츠의 유사성
**Date:** 11시간 전
**Category:** 스냅
**Original URL:** https://blog.naver.com/xpfkwh56/224416101794
---

1. 이 게임은 **설득** 의 게임

​

2. 고로, 세일즈 커뮤니케이션을 그대로 쓴다

​

1) 인사이트 제공 (Provision)

→ 고객이 **모르는** 것을 **알게 하는** 것

​

몰랐던 사실을 알려준다

물은 100도에서 끓어요 (x)

​

새로운 기준점을 준다

임계점이 도달해야 변화가 온다 (o)

​

2) 가치 전환 (Transfer/Switch)

→ 가치를 **'기능'** 에서

**'ID'** 로 전환하는 것

​

콘텐츠의 정보를 수용했을 때,

시선이나 기준, 관점이 바뀔 수 있어야 성공

​

3. 사람이 명품을 구입하는 이유

​

1) 티를 내고 싶어서 = 꾸꾸꾸

2) 티낸 티를 내지 않고 티내고 싶어서 = 꾸안꾸

​

둘 중 하나로 어젠다를 **'좁힌다'**

​

양측을 균형적으로 서술하는 것은

**'이야기'** 가 안 되고 설득도 안 된다

​

코카콜라 = 1등인데 맛있고 저렴합니다 (x)

어텐션 분산 → 실패

​

3. 딱 보기엔 로고도 없고, 겉만 봐서는

보세랑 다를 바 없는데 저걸 왜 사지?

​

경제적 여유가 있는 사람들은 (x)

→ 부자들은 = 말을 최대한 쉽게

​

**\* 구어로 다 바꿀 것**

​

부자들이 자랑하고 싶은 것은

**'로고'** 가 아니고 **'존재'** 다

​

브랜드를 드러내는 행위 → 짜침

​

저거 뭔데 저렇게 고급지지? (o)

타인에게 **'해석'** 되고 싶은 욕구 (o)

​

**4. 예시**

​

이 코트는 캐시미어라 따뜻하고, 디자인도 예쁨

→ 기능/보온성/미관 (x)

​

비싼 돈을 지불하는 이유는 무결점이다

​

에르메스를 **'입은'** 사람이 있고,

사람이 에르메스를 **'입었다'** 의 차이

​

비싼 물건은 **'불확실성'** 이 없다

불필요한 **'시행착오'** 를 만들지 않는다

​

**5. 디테일**

​

반드시 패션/뷰티 파트에선

**'가질 수 없는 것'** 을 떠들 것

​

이 분야는 환상을 파는 분야 라서

실제 그걸 가진 사람이 실측되면 **망함**

​

예쁜 여자도 별 거 없던데? (금기)

​

존예들은 어딜가도 사랑받고, 성격도 좋고,

노력 안 해도 갖고 싶은 건 다 가질 수 있고 (o)

​

예뻐도 안 그렇던데?

→ 너가 안 예뻐서 그럼

​

반증 가능성이 **차단** 될 수 있어야 됨

​
