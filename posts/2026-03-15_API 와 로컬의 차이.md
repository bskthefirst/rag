# API 와 로컬의 차이

1. 지피티, 제미나이가 끝인 줄 알았는데

이런저런 인공지능이 많구나를 알게 되면

​

결국 닿게 되는 종결점이 **'API'** 임

​

그리고 1m 토큰에 얼마냐,

속도는 어떠냐 이런 것을 봄

​

**\* 100만 토큰 하면**

**많은 것 같은데,**

**막상 쓰면 순식간임**

**​**

**피차 성능은 이제 알았으니까**

​

1) 이거 **내 목적** 이 진짜 중요하구나!

2) 결국 **확률** 이구나!

​

두 단계가 와야, 저 관점에 닿을 수 있음

​

**2. 확률**

​

벤치 믿지 말라고 하는 이유는 둘 임

​

1) 하나는 벤치를 돌리는 환경을

업체가 마음대로 조작할 수 있음

​

간혹 신규 업체들의 경우에는,

자기들은 벤치 과적합 안 한다

​

정말 투명하게 한다, 이렇게 하는데

그런 회사 열에 아홉은 금방 없어짐

​

**\* 회사 망하고 다들 학계로 감**

**​**

중국 모델의 일부는 실제 벤치도 좋고,

성능**도** 좋은데, 얘네도 마사지를 함

​

**\* 명확한 근거는 없지만**

​

2) 벤치 숫자가 **'성공률'** 임

​

즉, 문제를 10번 내서 3번 맞추면

30점, 8번 맞추면 80점 이렇게 감

​

내가 운이 지지리도 없어서,

인공지능 설치하고 과제 10개 줌

​

진짜 운이 없어서 다 틀리면?

**쓰레기!** 하고 지울 것이고

​

운이 좋아서 다 맞추면?

와 **신이다!** 하게 되는 것이 현실임

​

또 벤치에 98점 적혀 있어봤자,

미세 조정 몇 개 따라 **전부 다름**

​

모 중국 로컬 서비스의 경우에는

벤치 자체를 어차피 확인을 안 하니

대놓고 다 가라로 적어 버리는데

​

**학습 데이터 미공개** 하면 **끝** 임

​

블라거가 자기가 서울대를 나왔데,

근데 블로그 어디에도 내용이 없어

​

그런 일이 저기라고 크게 다르진 않음

​

3. API 를 쓰는 것은 마치 이런 것과 같음

​

잉공지능 좋다고 해서 쓰려고 했는데,

갑자기 물고기 하나를 덩그러니 줌

​

이게 뭐에요?

물고기 입니다 ㅇㅇ

​

살아있는 물고기가 펄떡펄떡 거리는데

내 손으로 직접 기절 시키고 죽여서

손질하고 요리를 전부 다 해야 됨

​

고개를 돌려, 옆을 보니까

으아악 비명 지르면서

물고기를 작살내고 있음

​

횟감에는 피가 안 나와서

물고기는 피가 없는 줄 알았는데

저 사람 주방은 피칠갑 된 상태임

​

4. 로컬을 쓰는 것은 이런 것과 같음

​

여긴 어디죠?

정신을 차려보니, 배 한 가운데

​

여기서 이제 내가 물고기든,

거북이든, 상어든, 고래든

​

알아서 잡아서 먹으면 됨

​

아니 이걸 어케해? 하고 있는데,

​

옆에선 잠수복 입고 뛰어들고 있는 놈

맨 몸으로 들어가는 놈, 작살 들고 있는 놈,

온갖 낚싯대 준비한 놈 등이 눈에 보임
